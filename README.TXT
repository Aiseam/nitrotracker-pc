NitroTracker v0.5
by 0xtob ^ 0x80 - (PC port QST)

NitroTracker is a FastTracker II style tracker originally designed for the Nintendo DS. It is a versatile tool for creating music everywhere, supporting the popular XM file format used by many PC trackers and playable on PC audio players such as Winamp or XMMS.
PC and Handheld Console Port
> Port Note: The original NitroTracker source code has been brought to PC while keeping the exact same real features as the Nintendo DS version. The main goal is to provide a faithful, functional codebase so that the community and developers can easily port it to other operating systems and handheld consoles.
